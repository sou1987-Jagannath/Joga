# Cannot Open Finance Shared Drive (S:) - Quick Help

Your data is safe.

If you cannot open the Finance shared drive (S:), try these steps in order:

1. Close all File Explorer windows.
2. Open File Explorer again and click This PC.
3. Right-click S: drive and choose Disconnect.
4. Restart your computer once.
5. After restart, sign in and wait 1 minute.
6. Open File Explorer and check if S: is back.

If S: is still missing:
1. In File Explorer address bar, type \\FINBRIDGE-FS02\Finance and press Enter.
2. If it opens, continue your work and still report it to Service Desk so mapping can be corrected.

If you get Access Denied or the folder does not open, contact Service Desk.

## Include these details in your ticket
- Your full name and work login name
- Team: Finance
- Time the problem started
- Exact message shown (for example: Access Denied)
- Whether S: is missing or visible but not opening
- Whether \\FINBRIDGE-FS02\Finance opens or not
- Your computer name (if known)
- Screenshot of the error (if possible)

Contact the Service Desk if S: still does not work after one disconnect and one restart.
